# My Portfolio Website

A responsive, dependency-free portfolio hosted on GitHub Pages.

All artwork and project previews are built with HTML/CSS/SVG. Project previews are labeled visual sketches, not product screenshots. No external fonts, analytics or JavaScript libraries are loaded. 

Use **Ctrl+K / Command+K** for quick navigation. The number game supports Enter, counts attempts, and remembers a personal best. Theme preferences also persist locally. Reduced-motion preferences are respected; content stays visible with JavaScript disabled.

Verified JavaScript syntax, internal links, asset references, unique element IDs and safe new-tab links. Rendered desktop/mobile browser verification remains outstanding because a browser binary was unavailable in the editing environment.

## Projects

The portfolio covers all six repositories as of 13 October 2026:

- **NextUp:** movie, TV and anime discovery, taste quiz, rule-based matching and watchlists.
- **Knightfall Chess:** bot and local chess games, interactive lessons and custom board styles.
- **NBA Shenanigans:** fantasy drafts, seeded playoff simulations and box-score exports.
- **Trading Platform Simulator:** paper trading with saved portfolios and historical replay. Its source repository is private, so the card has no public source link.
- **Habitz:** a Flask habit tracker with streaks, activity history and session-based sign-in.
- **Portfolio:** this responsive personal website.

Cards remain readable without JavaScript. The All work, Python, Web and Games filters update the visible project count. Total counts are derived from the cards when JavaScript is enabled.
